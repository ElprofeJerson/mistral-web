# Mistral AI · Qué es y sus usos

Página educativa de El Profe Jerson para introducir a estudiantes, docentes y público interesado en Mistral AI y sus aplicaciones.

**[Abrir la página web](https://elprofejerson.github.io/mistral-web/)**

## Qué encontrarás

- Una introducción a Mistral AI.
- Una selección de modelos y ejemplos de uso.
- Aplicaciones en redacción, asistentes, programación y análisis de información.

## Cómo utilizarla

Abre el enlace público desde tu navegador. Para consultar o adaptar el código, revisa `index.html`: contiene la estructura HTML y los estilos CSS. También puedes descargar el archivo y abrirlo en tu equipo; no requiere instalación.

## Sobre el proyecto

Es una página informativa; no incluye un chatbot ni conexión a una API. Las características de los modelos pueden cambiar: consulta la [web oficial de Mistral AI](https://mistral.ai/) para información actualizada.
